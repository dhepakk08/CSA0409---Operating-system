# CSA0409 Operating Systems

This repository contains the CSA0409 operating systems assignments and practicals.

## Contents

- `CO Assessments/` - course outcome assessments
- `Course Practicals/` - practical programs
- `Practice exrcises/` - practice exercises

## LinuxXplore

See [LinuxXplore/README.md](LinuxXplore/README.md) for the application overview and development commands.

cd LinuxXplore
